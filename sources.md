# Sources and Verification Notes

Last reviewed: 2026-07-28.

This explainer uses primary vendor documentation, security advisories, published research, and public guidance where possible. Prompt injection is an active area: defences change, vendors ship mitigations, and a technique that failed last month may work today. Treat these links as verification starting points, not permanent conclusions.

## How to read this

- Check the exact product, account type, feature, and version before assuming a described behaviour still holds.
- Prefer current vendor documentation, advisories, and peer-reviewed or reproducible research over marketing summaries and secondary commentary.
- Where a claim rests on a demonstration rather than a vendor statement, say so, and date it.
