# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, disagree on substance not on people. Vendor pitches dressed as contributions will be closed without drama — that's curation, not a moral judgement.

One thing specific to this repo: it explains an attack so ordinary people can spot it. Contributions that read as an attempt to arm someone rather than teach someone will be closed, and repeated attempts will end participation here.

Report concerns privately by email to <hello@aitutorium.com>.
