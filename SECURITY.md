# Security and Sensitive Data

Please do not open public issues or pull requests containing personal data, credentials, API keys, tokens, private keys, client material, or confidential examples.

Nothing in this repository is an attack tool. Demo payloads are benign by construction and must follow the payload rules in [CONTRIBUTING.md](CONTRIBUTING.md): no exfiltration, no tool or connector calls, no persistence, and no targeting of systems you don't own.

If you have found a live vulnerability in someone else's product, report it to that vendor, not here. For sensitive corrections to this repository, contact the maintainer through
[AI Tutorium](https://aitutorium.com).

If a contribution needs an example, use synthetic data.
